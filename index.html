Listas

Una por línea. Deben decir exactamente lo mismo que en la hoja «Parametros» de la planilla.

Reglas de seguridad

Péguelas en Firebase Console → Firestore → Reglas. Sin esto, cualquiera con la URL puede leer su clave.

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{doc=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Además active Authentication → Sign-in method → Anónimo.
